PUBRICA HOMEPAGE REDESIGN
=========================

Files
-----
index.html   Main responsive page
styles.css   Full responsive styling
script.js    Tabs, mobile menu, dropdowns, form message, reveal effects
assets/reference.png  Original reference image supplied in the conversation

How to run
----------
1. Keep all files in the same folder.
2. Open index.html in a browser.
3. For local development, serve the folder with any static HTTP server.

Notes
-----
- The structure and messaging are based on the supplied Pubrica reference image and the live Pubrica homepage.
- The visual system follows the reference: deep teal/navy, white content surfaces, lime accent, large rounded cards, soft shadows, and an abstract warm gradient used around the hero mockup.
- The form is front-end only. Connect it to your CRM/email endpoint before production.
